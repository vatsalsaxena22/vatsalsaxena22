## 👋 About Me

I'm **Vatsal Saxena**, a Full Stack Developer who enjoys turning ideas into functional, user-friendly web products.

I work across the development lifecycle—from building responsive frontend experiences and designing backend logic to integrating databases, APIs, and deployment workflows.

- 💼 **Currently:** Full Stack Developer at [Enkidu Technologies Pvt. Ltd.](https://enkidu.in/)
- 🌐 **Portfolio:** [vatsalsaxena22.github.io](https://vatsalsaxena22.github.io/)
- 💻 **Core stack:** JavaScript, React.js, Node.js, PHP, MySQL, and MongoDB
- 🎨 **Frontend:** HTML5, CSS3, Bootstrap 5, Tailwind CSS, and responsive UI development
- ⚙️ **Backend:** Node.js, Express.js, PHP, REST API integration, and database-driven applications
- 🗄️ **Databases:** MySQL and MongoDB
- 🚀 **Workflow:** Git, GitHub, Docker, Postman, Netlify, and Vercel
- 🧩 **Additional experience:** WordPress, WooCommerce, CMS development, and client websites

I value clean code, maintainable architecture, thoughtful UI/UX, and solutions that solve real problems.
